# 🚀 Space Ship Simulation (Варіант 6)

Програма для моделювання руху космічного корабля в умовах відсутності опору середовища, розроблена мовою C++ з використанням бібліотеки SFML, пакетного менеджера vcpkg та системи збирання CMake.

## 📋 Особливості програми
* **Фізична модель:** Рівномірний прямолінійний рух за інерцією та керований розгін під дією реактивної тяги (метод Ейлера з урахуванням кроку часу $\Delta t$).
* **Керування в реальному часі:**
  * `W` або `Стрілка вгору` — увімкнути/вимкнути двигун тяги.
  * `A` / `D` або `Стрілки вліво/вправо` — поворот корабля (зміна вектора тяги).
* **Візуалізація:**
  * Графічний трикутний контур космічного корабля.
  * Динамічне побудування та виведення лінії траєкторії руху (`sf::VertexArray`).
  * Текстова панель телеметрії (швидкість, поточні координати, стан двигуна, кут орієнтації).

## 🛠️ Вимоги до середовища розробки
* Операційна система: Windows / Linux / macOS
* Компілятор C++ із підтримкою стандарту **C++17** (або новішого)
* Система збирання: **CMake 3.20+**
* Менеджер пакетів: **vcpkg** (у режимі маніфесту)
* Графічна бібліотека: **SFML (3.x)**
